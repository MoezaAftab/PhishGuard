REST API Documentation & Playground

Direct programmatic access to each of PhishGuard's 5 autonomous agents and ensemble pipeline.

Check Health JSON
POST
/api/v1/scan

Runs the complete 5-agent ensemble across URLs, email content, and RFC822 headers. Saves report into {{ db_status.engine }}.

Example Request Body (JSON) 
{
  "url": "http://secure-login.paypa1-update.xyz/verify",
  "subject": "URGENT: Account Suspension Notice",
  "body": "Dear customer, click here within 24 hours to update your billing details.",
  "headers": {
    "From": "Security Desk ",
    "Authentication-Results": "spf=fail dkim=fail"
  }
}
cURL Example 
curl -X POST http://localhost:5000/api/v1/scan \
  -H "Content-Type: application/json" \
  -d '{"url": "http://paypa1.xyz"}'
POST
/api/v1/agents/url

Invokes Agent 1: URL Security Inspector for typosquatting, domain entropy, punycode, and lexical analysis.

Request Body 
{
  "url": "http://192.168.1.50/login"
}
POST
/api/v1/agents/content

Invokes Agent 2: Social Engineering Analyst to detect urgency cues, credential traps, and fake incentives.

Request Body 
{
  "subject": "URGENT: Confirm Your Identity",
  "body": "Your bank card has been frozen. Enter password now."
}
POST
/api/v1/agents/header

Invokes Agent 3: Header & Authentication Verifier to validate SPF, DKIM, DMARC, and From-vs-Reply-To alignment.

Request Body 
{
  "headers": {
    "From": "Support ",
    "Reply-To": "hacker@evil.ru",
    "Authentication-Results": "spf=fail dkim=fail"
  }
}
POST
/api/v1/agents/threat-intel

Invokes Agent 4: Threat Intelligence & DNS Verifier for live MX record checks, DNS A records, dynamic DNS, and SSRF prevention.

Request Body 
{
  "url": "http://subdomain.duckdns.org/payload"
}
POST
/api/v1/agents/ml

Invokes Agent 5: Explainable ML Classifier to compute statistical threat vectors and feature importance attribution.

Request Body 
{
  "url": "http://paypa1-update.xyz/verify",
  "body": "Immediate verification required."
}
GET
/api/v1/scans?limit=20

Retrieves list of past threat assessments saved in {{ db_status.engine }}.

GET
/api/v1/scans/<scan_id>

Retrieves complete assessment report JSON by its unique identifier.

GET
/api/v1/stats

Returns aggregate statistics: total scans, safe count, critical count, and average threat score.

GET
/api/v1/health

Returns operational status of all 5 security agents and the connected database engine.
